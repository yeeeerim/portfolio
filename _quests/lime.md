## 1. 프로젝트 개요

LIME은 취미 관련 상품 구매 결정을 돕기 위해 개발된 서비스입니다.

취미 상품 구매는 일반 상품과 달리 구매자의 취미 경험과 전문성이 필요하며, 개인의 기호에 맞는 상품 조합을 고려해야 하는 경우도 있습니다. 이러한 요구를 충족시키기 위해, 다양한 전문성을 가진 사람들이 취미 상품에 대해 자유롭게 의견을 묻고 피드백을 받을 수 있는 플랫폼을 제공하고자 기획하게 되었습니다!

## 2. 주요 기능

- **홈** : 다양한 취미 상품과 투표 관련 최신 정보를 제공하는 메인 페이지
- **소셜로그인** : OAuth 기반 소셜 로그인 및 회원가입 기능
- **아이템 관리**: 사용자가 새로운 아이템을 생성하고, 추가하며, 조회하고 검색할 수 있는 기능
- **찜 목록**: 사용자가 관심 있는 아이템을 폴더별로 관리할 수 있는 기능
- **투표 시스템**: 사용자가 투표를 생성하고, 조회할 수 있는 기능
- **마이페이지**: 사용자 프로필 및 활동 내역을 관리하는 페이지

## 3. 담당 역할

프론트엔드 개발:

1. 아이템 목록 페이지: 무한 스크롤 기능을 적용하여 사용자 경험을 개선
2. 찜 목록 및 상세 페이지: 폴더 생성/삭제, 폴더 이동, 폴더 이름 수정 등의 기능을 개발
3. 검색 기능: 사용자들이 원하는 취미 상품을 빠르게 찾을 수 있도록 구현
4. 레이아웃 및 반응형 UI: 다양한 디바이스에서 일관된 사용자 경험을 제공하기 위해 반응형 UI 가이드라인을 설계 및 개발

## 4. 기술 스택 선정 배경

- **Next.js 13**: App Router 학습 및 서버사이드 렌더링(SSR)을 통한 초기 로딩 속도 최적화를 위해 도입
- **React-Query**: 데이터 패칭 및 캐싱을 효율적으로 처리하여 상태 관리의 복잡성을 줄이고, 개발 생산성을 높이기 위해 도입
- **Tailwind CSS**: 일관된 디자인 시스템 구축과 생산성 향상 및 유지보수성 개선을 위해 도입

## 5. 성능 최적화

- 무한 스크롤: 아이템 목록 페이지에 무한 스크롤을 적용하여 초기 로딩 시간을 줄이고, 사용자 경험을 개선
- 서버사이드 렌더링: Next.js의 서버사이드 렌더링 기능을 활용하여 페이지 로딩 속도를 최적화
- React-Query: 데이터 패칭 및 캐싱을 통해 네트워크 요청 수를 줄이고, 응답 속도를 개선

## 6. 회고

LIME 프로젝트는 백엔드 3명, 프론트엔드 2명, 디자이너 1명으로 구성하여 진행한 팀 프로젝트입니다.

정기적인 온라인 회의를 통해 기획과 진행 상황을 공유하고, `Notion`, `Slack`, `Jira` 를 활용해 체계적으로 프로젝트를 관리했습니다.

프론트엔드 개발자가 두 명뿐이었지만, 커밋 컨벤션과 브랜치 네이밍 규칙을 명확히 정하고 코드 리뷰 시스템을 도입하여 코드 품질을 높였습니다.
이전 회사에서는 코드 리뷰 문화가 정착되지 않아 실현이 어려웠지만, 이번 프로젝트에서는 서로의 코드를 꼼꼼히 확인하며 실수를 사전에 방지하고, 더 나은 구현 방식을 논의하는 과정에서 코드에 대한 이해도와 팀 내 소통 능력을 함께 키울 수 있었습니다. 특히, 복잡한 로직을 단순화하거나, 공통 컴포넌트로 리팩토링하는 등 실질적인 개선이 이루어졌고, 코드 리뷰가 단순한 확인이 아닌 "성장"의 도구임을 실감했습니다.

처음에는 경력자로서 토이 프로젝트가 이직 준비에 실질적인 도움이 될지에 대한 의문도 있었지만, 새로운 기술을 적극적으로 사용해보며 팀원들과 협업하는 과정에서 많은 것을 배울 수 있을 것이라는 확신으로 책임감을 가지고 참여하게 되었습니다.

특히, `Next.js` App router 구조를 직접 다뤄보면서 폴더 구조 설계와 라우팅 전략에 대한 이해도를 높였고, `React-Query`를 활용해 데이터 패칭과 캐실 로직을 실제로 적용하면서 비동기 처리에 대한 감각도 익혔습니다.

이번 프로젝트는 단순한 토이 프로젝트를 넘어, 실무에서 바로 활용할 수 있는 기술을 경험하고 팀 협업 역량을 키운 뜻깊은 시간이었습니다. 이 경험을 통해 앞으로도 계속 성장할 수 있다는 자신감을 얻게 되었습니다. 😇
