## 1. 프로젝트 개요

학생들의 시간표와 출결 정보를 제공하기 위해 제작된 사이트입니다.

기존에는 학원에서 Google 스프레드시트를 통해 관련 정보를 공유해 왔으나, 모바일 환경에서 확인이 불편하고 접근성이 떨어지는 문제가 있었습니다. 이를 개선하고자, 학생들이 시간표와 출결 정보를 보다 쉽고 편리하게 확인할 수 있는 웹사이트를 직접 기획하고 개발하게 되었습니다.

현재는 스프레드시트 데이터를 웹사이트와 연동하여 출력하는 기능만 제공하고 있지만,
향후에는 데이터베이스를 도입하여 관리자가 웹사이트 상에서 직접 학생 정보를 입력하고 관리할 수 있도록 기능을 확장할 예정입니다.
또한, 학원의 시스템을 외부에 공유하고, 홍보할 수 있는 사이트로 발전시켜 나가는 것을 목표로 하고 있습니다.

## 2. 주요 기능

- **로그인/로그아웃** : 학생 개별 로그인 기능을 구현하여 본인 정보만 확인 가능하도록 보안을 강화했습니다.
- **주간시간표** : 학생의 주간 수업 일정을 시간표 형식으로 제공합니다
- **월간시간표** : 월간 수업 일정을 달력 형태로 제공합니다.
- **출결정보 캘린더** : 학생의 출결 정보를 달력 형태로 제공합니다.
- **출결정보 통계** : 출석, 지각, 결석 정보를 통계화하여 그래프로 제공합니다.
- **자습교재 현황** : 학생의 자습교재 진행 상황과 오답률을 제공합니다.
- **학생관리** : 관리자만 접근 가능한 페이지로, 사용자 정보를 확인 및 갱신할 수 있는 기능을 제공합니다.

## 3. 기술 스택 선정 배경

- **Frontend**: React, Next.js 14
  - 최신 기능과 성능 최적화를 위해 선택
- **Backend**: Next.js API Routes
  - Serverless 환경에 적합하며 간단한 API 서버 구축
- **데이터 연동**: Google Sheets API
  - 기존 스프레드시트 데이터를 유지하며 빠르게 연동 가능 (기존 시스템과의 호환성 확보)
- **배포**: Vercel
  - 무료 요금제를 활용한 Serverless 배포 환경 제공

## 4. 성능 최적화

- **SWR 캐싱**: 자주 변경되지 않는 데이터는 클라이언트 측에서 캐싱하여 API 호출 횟수를 최소화하였습니다.
- **데이터 최소화**: Google Sheets API 호출 시, 필요한 데이터만 선택적으로 불러와 데이터 전송 크기를 줄이고 효율성을 높였습니다.
- **서버사이드 렌더링**: Next.js의 서버사이드 렌더링 기능을 활용하여 페이지 로딩 속도를 최적화하고, Skeleton UI를 적용해 데이터 로딩 중에도 사용자 경험이 향상될 수 있도록 개선하였습니다.
- **모바일 최적화**: 모바일 사용자가 많은 점을 고려하여 반응형 UI를 개선하였습니다.

## 5. 문제 해결

### 문제 1: 데이터 갱신 속도

- **문제**: 스프레드시트 데이터 변경 시 사이트에 즉시 반영되지 않는 문제
- **해결**: Next.js의 `fetchCache` 옵션을 비활성화하여 새로 배포하지 않아도 항상 최신 데이터를 가져올 수 있도록 설정하였습니다.

### 문제 2: 브라우저 호환성

- **문제**: `table` 태그를 사용하여 시간표를 구현했으나, 병합된 셀에 대한 처리가 브라우저마다 상이하게 작동하는 문제
- **해결**: `grid` 레이아웃으로 변경하고, `grid-column`과 `grid-row` 속성을 활용하여 셀의 병합 영역을 명시적으로 설정하였습니다.

### 문제 3: 인증 보안

- **문제**: 로그인 정보의 보안 유지
- **해결**: 회원 정보를 JSON 형태로 `/tmp` 폴더에 저장하도록 구현하였습니다. 해당 데이터는 서버 내부에서만 접근 가능하도록 처리하여, 개발자와 사용자 모두 데이터를 확인할 수 없게 보안을 강화하였습니다.

### 문제 4: 개발자 의존성

- **문제**: 학생 개인 데이터는 실시간으로 반영되지만, 로그인 정보는 보안상의 이유로 실시간 반영이 어려운 문제 발생
- **해결**: `Vercel Deploy Hook`을 활용하여 관리자가 직접 배포를 수행할 수 있도록 시스템을 개선하였습니다.
  - 관리자로 로그인 시 배포 버튼을 제공하여, 관리자가 배포 작업을 수행할 수 있게 함으로써 개발자 의존도를 낮추고 운영 효율성을 높였습니다.

## 6. 회고

이번 프로젝트를 통해 서비스를 직접 기획하고 운영하는 전 과정을 경험하면서, 단순히 기능을 구현하는 것을 넘어 운영 효율성과 유지 비용까지 고려하는 것이 얼마나 중요한지 깨달을 수 있었습니다.
특히 제한된 리소스 내에서 최대한의 효율을 낼 수 있는 구조를 고민하고, 불필요한 비용을 줄이는 방향으로 설계하고 구현하는 과정은 실무적인 관점에서 매우 의미 있는 경험이었습니다.

또한, 학생들이 실제로 어떻게 이 서비스를 사용할지, 어떤 부분에서 불편함을 느낄 수 있을지를 지속적으로 고민하며 개선 방향을 모색하는 과정 속에서, 사용자 중심의 사고와 서비스 설계의 중요성을 더욱 깊이 체감할 수 있었습니다.

이러한 경험을 바탕으로, 앞으로도 단순히 ‘작동하는 서비스’에 그치지 않고, 실제 사용자에게 가치를 줄 수 있는 서비스를 만들기 위해 더욱 고민하고 발전해 나가고자 합니다.

## 7. 향후 계획

- **데이터베이스 도입**

  - 학생 및 출결 데이터를 사이트에서 직접 관리할 수 있도록 시스템을 개선하고, 기존 스프레드시트를 완전히 대체할 예정입니다.

- **단위 테스트 코드 작성**

  - 스프레드시트 데이터를 기반으로 입력된 값의 유효성을 검증할 수 있는 단위 테스트 코드를 작성할 계획입니다.
  - 이를 통해 관리자가 각 학생의 데이터를 사이트에서 일일이 확인하지 않아도, 데이터의 정확성과 신뢰성을 확보할 수 있도록 개선할 예정입니다.

- **PWA(Progressive Web Application) 개발**
  - 출결 상태 변화나 공지사항을 실시간으로 알릴 수 있는 알림 기능을 추가할 계획입니다.
  - 또한, 안드로이드 환경에서 웹앱 형태로 사용할 수 있도록 PWA 기술을 도입하여 접근성을 강화할 예정입니다.
