## 1. 프로젝트 개요

메이플스토리 게임 캐릭터의 능력치를 기준으로 환산된 주스탯(주요 스탯)을 계산해주는 도구입니다.<br>
직업별로 다른 능력치 반영 비율을 적용하여 실제 전투력에 가까운 수치를 제공합니다.<br>
이를 통해 유저는 장비나 스탯 배분의 효율을 비교하고 최적화할 수 있습니다.

현재 하루 약 **3만 명**이 이용 중인 서비스로, 보안상의 이유로 Repository는 Private로 관리되고 있습니다.

## 2. 주요 기능

1. **메인** : 캐릭터를 검색하고 즐겨찾기한 캐릭터를 확인할 수 있는 페이지
2. **직접 입력** : 상세 스탯을 직접 기입하여 환산 결과를 출력하는 입력 폼 페이지
3. **캐릭터 정보** : 넥슨 오픈 API를 통해 가져온 캐릭터 아이템을 상세히 보여주고, 환산 결과를 계산하여 출력하는 페이지
4. **분석/최적화** : 캐릭터의 스탯을 분석하고 최적화하는 페이지 모음
5. **스펙업 효율** : 스타포스, 잠재능력, 추가옵션, 심볼 효율을 계산해주는 기능 제공
6. **경험치 효율** : 각종 컨텐츠에 대한 경험치 효율을 계산해주는 페이지
7. **시뮬레이터** : 메이플스토리의 각종 이벤트를 시뮬레이트 할 수 있는 페이지
8. **이용 가이드** : 환산주스탯 이용 가이드 모음
9. **환산 랭킹** : 환산 랭킹을 보여주는 페이지
10. **기록실** : 보스 명예의 전당을 기록하는 페이지
11. **챌린지** : 최소컷/타임어택 챌린지를 제공하는 페이지
12. **사이트맵** : 환산 주스탯 사이트맵을 제공하는 페이지
13. **링크 모음** : 메이플스토리 관련 유용한 링크 모음

## 3. 담당 역할

- UI 디자인 및 프론트엔드 개발
- UI/UX 개선 및 반응형 웹 개선
- Styled-component를 tailwind CSS로 전체 스타일링 변경
- 프로젝트 코드 품질 개선

## 4. 회고

"환산 주스탯" 은 처음에 스프레드시트로 제작되어, 메이플스토리 유저 사이에서 널리 사용되던 서비스였습니다. 하지만 시간이 지나면서 유지보수가 점점 어려워졌고, 이를 보완하게 위해 웹 버전이 출시되었습니다.
웹사이트에 처음 접했을 때, 입력란과 버튼의 구분이 모호하고, 모바일 환경에서는 모달이 잘리는 등 UI/UX 개선이 필요하다고 느껴졌습니다.

이에 직접 연락할 수단을 찾아 UI/UX 개선에 대한 의견을 적극적으로 전달했고, 긍정적인 피드백을 받아 프로젝트에 합류하게 되었습니다.

디자이너가 따로 없는 상황이었기 때문에, Figma를 활용해 직접 디자인 작업을 진행했고, 퍼블리싱을 통해 전반적인 UI/UX를 개선했습니다. 그리고, 기존에 `styled-component`로 구현되어 있던 스타일 코드를 전부 `tailwind CSS` 로 마이그레이션하여 성능과 로딩 속도도 향상시켰습니다.

회사에서는 보통 디자인팀과 기획팀이 따로 있어, 개발자는 Figma를 보고 개발만 하면 되었기 때문에 UX를 깊이 고민할 기회가 없었습니다. 하지만 이번 프로젝트를 진행하면서 실 사용자들의 피드백을 직접 반영하며 UX를 고민할 수 있었고, 이는 프론트엔드 개발자로서 매우 의미 있는 경험이었습니다.

보수가 없는 프로젝트였지만, 그 어느 때보다 열정을 쏟아 개발에 임했습니다. 사용자들에게 빨리 보여주고 싶은 마음에 새벽 7시까지 몰입해 작업한 날도 있을 만큼, 큰 성취감을 느낄 수 있던 프로젝트였습니다.
